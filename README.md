# Ideas Vault - Backend API

This is the backend repository for the **Ideas Vault** application. It handles user authentication, session management, and core API business logic for storing and interacting with ideas.

---

## 🛠️ Tech Stack & Architecture

- **Runtime:** Node.js / Next.js API Routes (or Express.js)
- **Database:** [MongoDB]
- **Authentication:** Better Auth (with Google Social Login support)
- **Styling/UI Components:** HeroUI (for frontend compatibility)
